# 055 — Aprobación de recomendaciones D01–D07

Fecha: 2026-10-21. Autoridad: Product Owner, conversación vigente.

El Product Owner declaró expresamente «apruebo recomendaciones D01-D07» después de recibir la spec 055, su hoja DECISIONES-PRODUCT-OWNER.md y la revisión conjunta con Claude. Se aprueban las recomendaciones de custodia institucional explícita, nuevas autorizaciones humanas/finalidad, validación por visitador competente, semántica de repeticiones/tiempo/episodios, seguimiento y entrega incremental.

Codex cierra contratos técnicos por paquete y audita. Claude Code implementa código y pruebas bajo esos contratos. Los registros de competencia y los fixtures no constituyen acreditación ni validación clínica automática. Campos y reglas clínicas reales requieren responsables competentes; el desarrollo/aceptación inicial usa únicamente datos ficticios aislados.

La autorización previa para compartir con Anthropic se conserva dentro de la spec y código/documentación relacionados, excluyendo secretos, bases y datos reales. No se autoriza Git, PR, merge, publicación, despliegue ni usar datos reales. No se ejecuta confirm-user-consent.sh por iniciativa del agente; el log refleja el acto explícito del Product Owner, sin inventar consentimiento.

Ejecución: MP01-CUSTODIA-Y-PERMISOS.md concreta el primer paquete. El gate global no sustituye suficiencia ni auditoría antes del siguiente paquete. D01 no adopta la alternativa de equiparar tenant con una institución; se conserva separación entre instituciones del mismo tenant y entre tenants.
