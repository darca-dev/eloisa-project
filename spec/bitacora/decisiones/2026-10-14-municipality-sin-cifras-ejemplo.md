# Municipality con registros guardados

PO: «necesito retirar la pantalla tecnica necesito datos reales».
Se continúa 043 para el acceso visual y se acota 044 a retirar fixtures de la
ruta operativa municipal, usando exclusivamente APIs persistentes existentes.
Se preguntó opcionalmente por fuente externa; mientras no haya una, se utiliza
la base actual, sin cargar ni inventar información institucional.

Población/Territorio conservan consultas reales protegidas. Inicio obtiene su
resumen de esas APIs. Los otros diez apartados conservan navegación y explican
que están pendientes de habilitar; no se presentan como módulos implementados
ni como registros vacíos de un backend que aún no existe.

No se borran datos ni la cuenta de prueba solicitada. Registros persistidos en
este entorno local no equivalen a datos oficiales. No se atribuye Soacha, una
Secretaría, presupuesto, indicadores, actividad o periodos al usuario sin fuente.
No se implementan nuevos permisos/endpoints/tablas ni S02–S14 completos.
