# Investigación 032 — Agenda y citas: canvas demo local

## Diferencia confirmada

El canvas contiene cuatro solicitudes, un calendario mensual de siete columnas
con días de semana, totales y una tarjeta de estados/perspectivas. La Agenda
actual conectada muestra controles de ventana, datos servidos y una lista de
citas; en demo recibe solo una solicitud y un día de datos. Las composiciones
no son equivalentes.

## Decisión

No se altera la Agenda conectada: expresa permisos y comportamiento real. Se
creará una presentación demo local aislada, igual que la bandeja demo de
Visitas, exclusivamente para el montaje de demostración.
